ТИХИЕ СТРАНИЦЫ STUDIO 3.3 — СТИКЕРЫ И РАМКИ

Готовый исходный проект SwiftUI для iPadOS 17 (iPad 6-го поколения).
Это обновление к проекту STUDIO 3.2; приложение не было собрано или протестировано на реальном iPad.

Встроено: 127 видов стикеров, из них 32 большие прозрачные декоративные рамки.
Структура: вкладки Все, Рамки, Цветы, Ленты, Записки, Уют, Винтаж, поиск по русским названиям.
Дополнительно: перемещение по странице, масштабирование двумя пальцами, поворот, контекстное меню для порядка слоёв.
Офлайн: изображения уже внутри Assets.xcassets, интернет для их использования не нужен.

Установка через GitHub Desktop (из РАСПАКОВАННОГО АРХИВА):
1. Сделайте копию своего локального репозитория на всякий случай.
2. Скопируйте папки Sources, Resources и QuietPages.xcodeproj в каталог quiet-pages-ipad с заменой совпадающих файлов.
   НЕ УДАЛЯЙТЕ папку .github/workflows и старые файлы проекта.
3. Откройте GitHub Desktop: Commit to main, затем Push origin.
4. На GitHub Actions запустите Собрать приложение для iPad, проверьте, что сборка зелёная.
5. Скачайте IPA из Artifacts и установите через Sideloadly, предварительно создав резервную копию записей.

ВАЖНО: для iOS-сборки требуется macOS/Xcode (например, GitHub Actions); Swift в этом архиве проверяется здесь лишь на синтаксис.
