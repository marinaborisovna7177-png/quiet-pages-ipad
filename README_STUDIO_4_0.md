# Тихие страницы — STUDIO 4.0

Исходный проект нативного приложения для iPad (iPadOS 17.7.11, iPad 6-го поколения).

## Изменения
- 127 PNG-украшений, разложенных по категориям и поиск по названиям. Ленты, фотообрамления, бумажные записки, цветы и другие элементы.
- 93 шаблона бумаги, 36 обложек.
- PencilKit: ручка, перо, линер, карандаш, фломастер, акварель, мелок и ластик. Цвет, толщина.
- Undo/Redo для изменения содержимого текущей страницы — тексты, бумага, стикеры, рукописные линии (до 70 шагов в памяти текущего запуска).
- Удерживайте наклейку: поворот на 15°/90°, слои, копирование, удалить, текст на наклейке. Поворот и размер доступны жестом двух пальцев.
- В режиме «Писать сверху» можно писать пальцем/стилусом поверх наклеек.
- Набранный текст, привязанный к наклейке, следует за её перемещением, поворотом и изменением размера.
- Расширены записки для письма и добавлены прозрачные поля по краям отдельных PNG, чтобы уменьшить риск обрезки.

## Обновление в GitHub Desktop
1. В GitHub Desktop выберите `quiet-pages-ipad` → `Show in Explorer`.
2. Распакуйте архив, скопируйте **Sources**, **Resources**, **QuietPages.xcodeproj** в папку репозитория с заменой. Сохраните папку `.github/workflows`.
3. В GitHub Desktop: Summary `Тихие страницы STUDIO 4.0` → **Commit to main** → **Push origin**.
4. Откройте GitHub → Actions → **Собрать приложение для iPad** → **Run workflow**, ветка `main`.
5. После успешной сборки → **Artifacts → QuietPages-IPA** → распаковать `.ipa` → установить через Sideloadly.

**Это не готовый IPA.** В этой среде выполнена проверка синтаксиса Swift и ресурсов; Xcode-сборка и тест на iPad не выполнены. Если сборка выдаст ошибку, скачайте лог GitHub Actions.

**Данные:** Перед обновлением экспортируйте важные записи. Не удаляйте прежнюю версию приложения с iPad. Устанавливайте с тем же bundle ID и Apple ID для сохранения локальных данных. Бесплатная подпись Sideloadly обычно действует 7 дней.

**Ограничения:** история отмены хранится в памяти и после перезапуска недоступна; undo/redo не охватывает создание или удаление целых блокнотов. Рукописный рисунок поверх наклейки пока не привязан к ней при перемещении (наборный текст привязан). Нет непрерывного теста на физическом iPad.
