ТИХИЕ СТРАНИЦЫ • STUDIO 3.2
Для iPad 6-го поколения с iPadOS 17.7.11

Что добавлено:
• 36 встроенных обложек, сгруппированных в 4 коллекции.
• 93 вида бумаги и планеров, разбитых на категории.
• Поиск шаблонов по русским названиям.
• Возможность сменить обложку существующего блокнота: длительное нажатие на блокнот в библиотеке → «Сменить обложку».
• Превью бумаги показывает рисунок страницы до применения; бумага сохраняется офлайн.
• Печатные страницы в PDF используют тот же узор бумаги, что и редактор.
• Сохранена возможность рисовать/писать на стикерах в режиме «Писать сверху» и вводить текст двойным касанием по наклейке в режиме расстановки.

УСТАНОВКА ОБНОВЛЕНИЯ
1. Откройте GitHub Desktop -> quiet-pages-ipad -> Show in Explorer.
2. Распакуйте этот архив. Скопируйте папки Sources, Resources и QuietPages.xcodeproj в каталог quiet-pages-ipad, подтвердите замену файлов. Остальные файлы не удаляйте.
3. GitHub Desktop: заполните Summary («Больше обложек и бумаги — STUDIO 3.2»), Commit to main, Push origin.
4. GitHub -> Actions -> «Собрать приложение для iPad» -> Run workflow. Скачайте IPA из успешной сборки, установите через Sideloadly.

ВАЖНО
Архив содержит ИСХОДНЫЙ КОД, не готовый IPA. Swift проверен синтаксически (swiftc -frontend -parse), но сборка Xcode и работа на iPad в этой среде не проверялись. Если сборка GitHub выдаст красный крест, скачайте лог.
Старую версию не удаляйте без резервной копии записей. Используйте тот же Apple ID и bundle ID для обновления.
