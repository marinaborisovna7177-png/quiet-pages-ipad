ТИХИЕ СТРАНИЦЫ · STUDIO 4.0 (исходный проект iPadOS 17)

Что изменено:
• Каталог из 127 PNG-наклеек: рамки, цветы, ленты, записки, уют и винтаж. Поиск и категории, прозрачные рамки.
• 93 вида бумаги и планеров, 36 обложек.
• 8 инструментов PencilKit: ручка, перо, линер, карандаш, фломастер, акварель, мелок, ластик; толщина и цветовая палитра.
• Кнопки «Отменить» и «Вернуть» для изменений на текущей странице (декор и чернила). Локальная история до 70 шагов; после закрытия приложения не сохраняется.
• Текст на стикере: двойное касание в режиме «Двигать наклейки», либо удерживание -> «Напечатать на наклейке».
• Наклейки двигаются, увеличиваются двумя пальцами и вращаются. Есть меню поворота на 15°/90°, передний и задний план. Напечатанный текст перемещается и вращается вместе с наклейкой.
• Рукописная надпись отображается ПОВЕРХ стикеров в режиме «Писать сверху». При последующем перемещении наклейки такой рисунок пока остаётся на бумаге.
• Локальное сохранение, офлайн, экспорт PDF. Никаких платных наборов и подписок.

УСТАНОВКА
1. В GitHub Desktop открой quiet-pages-ipad -> Show in Explorer.
2. Содержимое этого архива (Sources, Resources, QuietPages.xcodeproj) скопируй в папку репозитория с заменой. Папку .github не удаляй.
3. GitHub Desktop -> Summary «STUDIO 4.0 · Стикеры и инструменты» -> Commit to main -> Push origin.
4. GitHub -> Actions -> «Собрать приложение для iPad» -> Run workflow. Если появится зелёная галочка, скачай артефакт IPA и установи через Sideloadly.
5. Перед обновлением сохрани важные записи; старое приложение не удаляй. Подпись Sideloadly Free обычно требует обновления каждые 7 дней.

ПРОВЕРКА
Это исходный проект, а не подписанный IPA. Проверена структура и синтаксис swiftc -frontend -parse; реальная Xcode-сборка и запуск на iPad 6 здесь недоступны. При ошибке нужна копия GitHub Actions log.
