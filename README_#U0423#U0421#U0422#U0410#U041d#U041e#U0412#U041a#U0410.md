# «Тихие страницы» — настоящее приложение для iPadOS 17

Это **нативный проект SwiftUI**, а не HTML, не PWA и не сайт. Он использует PencilKit, PhotosPicker и файлы самого iPad. Интернет для **работы приложения после установки** не нужен. Нет учётной записи, рекламы, платного контента или сетевых сервисов.

## Возможности

- Красивые блокноты с шестью обложками, перелистываемыми страницами и восемью видами бумаги.
- Записи пальцем или стилусом, три инструмента: ручка, маркер, ластик, выбор цвета.
- 18 декоративных стикеров в локальном пакете и добавление своих фотографий.
- Добавление текста и перетаскивание предметов по страницам; долгое нажатие удаляет элемент.
- Автосохранение блокнотов в память iPad, работа в авиарежиме.
- Экспорт целого блокнота в PDF через системное меню «Поделиться».

## Совместимость

Проект рассчитан на **iPadOS 17 и новее** и **iPad 6-го поколения**. Проверка синтаксиса Swift и структуры проекта выполнена, но фактическая сборка Xcode и тест на iPad не проводились в текущей среде.

## Как получить IPA, если компьютер только с Windows

### Бесплатная сборка на GitHub Actions

1. Создайте бесплатный аккаунт на https://github.com (если нет).
2. Создайте **пустой** репозиторий, например `quiet-pages-ipad` (не загружайте туда личные заметки). Для бесплатной сборки удобен публичный репозиторий с кодом — заметки не будут публиковаться.
3. Распакуйте этот ZIP на Windows. В репозитории выберите **Add file → Upload files** и загрузите **всё содержимое** папки проекта, сохранив пути, особенно `.github/workflows/build-ios.yml`. Веб-интерфейс GitHub может не показывать скрытую папку `.github` в некоторых сценариях — проверьте, что файл действительно оказался по пути `.github/workflows/build-ios.yml`.
4. Откройте вкладку **Actions → Собрать приложение для iPad → Run workflow**.
5. После успешного выполнения скачайте артефакт **QuietPages-IPA** и извлеките `QuietPages-unsigned.ipa` из ZIP.
6. Подключите iPad к Windows, откройте Sideloadly, выберите этот IPA и подпишите собственной учётной записью Apple. Следуйте запросам Sideloadly. Режим разработчика уже должен быть включён с прошлой установки.

Если GitHub не собирает проект, смотрите подробный лог в шаге «Собрать iPadOS приложение без подписи». Исправления потребуют изменения исходного проекта.

### Вариант с Mac

Откройте `QuietPages.xcodeproj` в Xcode, выберите iPad, включите автоматическую подпись и запустите сборку.

## Обязательное ограничение Apple

При бесплатной подписи для личного устройства **сертификаты/профили обычно действуют 7 дней**. После этого приложение придётся снова подписывать. Без платного разработческого аккаунта и публикации нельзя обещать бесплатный IPA, который будет бессрочно запускаться офлайн. Приложение умеет работать без интернета после запуска, но подпись на устройстве всё равно должна оставаться действительной.

## Где лежат данные

Все записи хранятся локально в каталоге Application Support приложения. **Не удаляйте приложение** до экспорта нужных блокнотов в PDF или создания резервной копии всего iPad: удаление приложения обычно удаляет его локальные данные. Экспорт PDF сохраняет вид страниц, но не заменяет редактируемую резервную копию.
