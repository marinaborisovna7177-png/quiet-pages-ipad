# «Тихие страницы» STUDIO 4.0 — обновление исходного проекта

Версия проекта: 6.0 (iPadOS 17+, SwiftUI + PencilKit). Это исходники, НЕ готовый IPA.

## Что в этом пакете действительно реализовано

• Исправление: после вставки стикера, фото или текста снова можно писать по всему листу. Режим «Двигать» включается только явным нажатием. Кнопка «Писать» теперь доступна в верхней панели.
• Комбинированная панель с быстрым доступом к 8 видам чернил, цветам, стикерам, слоям и фигурам; дополнительная нижняя панель.
• Режим геометрических фигур: круг, прямоугольник, линия, стрелка (можно перемещать и изменять размер).
• Слои: порядок, видимость, закрепление, отражение, прозрачность, дублирование и удаление объектов; сгруппированные композиции можно разъединять.
• Набор наклеек: 2 000 исходных PNG из уже имеющихся архивов StickerPacks + 1 000 композиций, собираемых из исходных изображений прямо в приложении. Каждая композиция вставляется как два редактируемых элемента. Помимо этого, в проекте уже есть основные стикеры и рамки.
• 30 тематических групп в расширенной библиотеке (20 первоначальных + 10 групп композиций), поиск, «Избранное», «Недавние».
• Бумага: 93 прежних варианта + 147 новых сочетаний цветов и разметок = 240. Все работают без интернета; это не 240 отдельно нарисованных акварельных картинок.
• Обложки: 36 первоначальных изображений + 108 цветовых вариаций, созданных поверх этих исходных дизайнов = 144 оформления; это не 144 уникальных фотореалистичных иллюстрации.
• 24 палитры оттенков для текста и письма, плюс свободный выбор цвета.
• «Эстетичная мастерская»: 9 направлений и возможность менять обложку и бумагу перед созданием блокнота; быстрая заметка.
• Шрифты: все доступные на iPad системные начертания с предварительным просмотром, ручная загрузка TTF/OTF. 120 специально лицензированных шрифтов в этот пакет НЕ входят.
• Резервное копирование одного редактируемого блокнота в файл .quietpages и восстановление из этого файла; экспорт PDF и импорт PDF сохранены.
• Совместимость с данными предыдущей версии: старые страницы и объекты декодируются с настройками по умолчанию.
• Файл Actions (build-ios.yml) автоматически извлекает 2000 исходных PNG до компиляции, проверяет их число и прикладывает отчёт ошибок Xcode.

## Важно

Синтаксис всех Swift-файлов проверен командой swiftc -frontend -parse. Полный типовой анализ Xcode, работа на iPad и установка IPA в данном окружении недоступны. Поэтому «готовой проверенной IPA» здесь нет: GitHub Actions должен скомпилировать проект на macOS, а затем нужно проверить приложение на твоём iPad.

Объём программы может увеличиться из-за 2 000 картинок внутри IPA. Если есть важные записи, не удаляй установленную версию. Перед переустановкой сохрани PDF или резервную копию, если она уже поддерживается текущей версией.

## Быстрое обновление на Windows 10 через GitHub Desktop

1. В GitHub Desktop открой quiet-pages-ipad → Repository → Show in Explorer.
2. Распакуй **QuietPages_STUDIO4_UPDATE_ALL.zip** (не копируй сам ZIP внутрь репозитория).
3. Из распакованного обновления скопируй **Sources**, **QuietPages.xcodeproj**, **.github** в корень открытого проекта. Выбери «Объединить папки» и «Заменить файлы». Другие папки НЕ удаляй, особенно Resources и StickerPacks.
4. В GitHub Desktop убедись, что отображаются изменения нескольких Swift-файлов, проекта Xcode и рабочего процесса.
5. В поле Summary: «Тихие страницы STUDIO 4.0 — редактор, оформление, наклейки» → Commit to main → Push origin.
6. Открой GitHub → Actions → самый новый запуск → при успехе скачать «QuietPages-IPA» → извлечь QuietPages-unsigned.ipa → установить через Sideloadly.
7. В блокноте проверь ручку, вставь стикер и повтори рисунок. Для перемещения стикера нажми «Двигать» на верхней панели; для рисования — «Писать».

**Альтернатива:** QuietPages_STUDIO4_FULL_PROJECT.zip содержит весь проект, включая старые 2000 изображений в четырёх архивах. Использовать его при первичном восстановлении проекта, а не заменять им существующие данные iPad.
