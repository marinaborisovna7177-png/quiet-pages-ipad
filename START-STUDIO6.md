# Тихие страницы Studio 6 — исходный кандидат

Проект не прошёл сборку Xcode и тестирование на физическом iPad. IPA в этом архиве нет. Отчёт: Docs/STABILITY-2026-11-24.md.

## Сборка
Открыть QuietPages.xcodeproj на Mac с Xcode и выбрать схему QuietPages. Все ресурсы включены. Выполнить Product → Test, затем сборку под iOS 17+.

Для GitHub: перенести содержимое этой папки в репозиторий quiet-pages-ipad (не вкладывать лишнюю папку). Workflow .github/workflows/build-ios.yml запускает проверки, XCTest на доступном iPad Simulator и сборку. Только после успешных шагов он упаковывает неподписанную IPA для последующей подписи. Доступ к GitHub для запуска из этого разговора не подключён; workflow пока не запускался.

Не удаляйте существующее приложение с записями. Перед установкой любой новой версии экспортируйте редактируемую резервную копию и сохраните её вне приложения. Наличие исходников и успешная сборка не заменяют проверку на iPad.

Для стороннего стилуса оставьте «Только Apple Pencil» выключенным. В верхней панели меню «Палец / стилус» есть «Постоянная толщина ручки и пера»; по умолчанию она включена. Это ровная линия без изменения толщины от давления. Для динамического пера её можно отключить.
