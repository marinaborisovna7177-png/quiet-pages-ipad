# Тихие страницы — STUDIO 5.0 · объединённое обновление

Это **исходный нативный проект SwiftUI**, а не готовая IPA. Проверка на iPad и компиляция Xcode выполняются после отправки в GitHub Actions. Сохраняем тот же идентификатор приложения `com.salipaper.quietpages` ради возможности установки поверх предыдущей версии без удаления данных.

## Действительно встроено

1. Библиотека блокнотов с двумя режимами отображения — книжная полка и сетка, папки, избранное, переименование и дублирование.
2. Мастерская нового блокнота: 16 настроений, выбор обложки, бумаги, цвета; быстрая заметка.
3. 288 вариантов бумаги: 240 ранее созданных форм/оттенков + **48 новых расписанных PNG-полей** (зима, весна, лето, осень, волшебная школа, винтаж). Центр чистый; три уровня насыщенности украшений. Письмо сохраняется при смене фона.
4. 168 оформлений обложек: 144 прежних вариантов + 24 новые художественные обложки (6 коллекций по 4).
5. 2 000 исходных PNG в `StickerPacks` с автоматической установкой в Assets до Xcode-сборки; 1 000 вариаций из 2 изображений, которые на странице редактируются по отдельности, а также базовые наборы.
6. Плавающая перемещаемая панель быстрого доступа; закрепляемая/перемещаемая библиотека наклеек, работающая **без модального закрытия листа**; свайпы и свободный рисунок после вставки.
7. Режимы письма/рисования/перемещения, шариковая, перьевая, монолиния, карандаш, маркер, акварель и мелок PencilKit, ластик по штриху и частичный ластик, лассо, толщины и прозрачность.
8. Декоративная кисть расставляет вдоль проведённой линии звёзды, цветы, листья, бантики и зимние элементы; составные украшения остаются объектами на странице.
9. Фото-студия (Core Image): фильтры, яркость, контраст, насыщенность, поворот, квадратная/круглая обрезка; редактор собственного PNG с удалением **светлого однородного фона** (не универсальное интеллектуальное выделение).
10. Импорт собственных изображений из «Фото» и «Файлов»; постоянная библиотека собственных PNG с повторным использованием.
11. Слои: порядок, скрытие, блокировка, прозрачность, отражение, дублирование. Сохранение всех видимых элементов как редактируемой пользовательской композиции и повторная вставка.
12. Шрифты: все системные на iPad, пользовательский импорт TTF/OTF, любимые стили надписей; **120 сторонних шрифтов не распространяются**.
13. 24 цветовые палитры, настройка цвета, избранные настройки пера.
14. Лента миниатюр страниц, изменение порядка через кнопки стрелок, дублирование; режим письма без панелей.
15. Автосохранение на устройстве, PDF-импорт/экспорт, резервная копия редактируемого блокнота, восстановление.

## Технические ограничения и честный статус

- В проект не включены посторонние лицензируемые шрифты. Количество системных начертаний зависит от самой iPadOS; дополнительно можно импортировать свои TTF/OTF.
- Тематика волшебной школы авторская: нет чужих логотипов и готовых официальных иллюстраций франшизы.
- Удаление сложного фона (волосы, множество объектов) не реализовано; есть ручной выбор формы и удаление почти белого фона.
- Новые декоративные кисти используют маленькие PNG-штампы, а не полноценный физический симулятор краски.
- Варианты обложек/бумаги включают цветовые производные: они не все нарисованы как уникальные изображения.
- Пока нет проверенной IPA. На Linux проверены синтаксис Swift, структура Xcode-проекта, 2 000 архивных PNG, 48 новых художественных PNG и 24 обложки. GitHub Actions должен выполнить Xcode-сборку.

## Обновление через GitHub Desktop (Windows 10)

**Сначала сделай резервную копию записей в текущем приложении**, если они важны. Не удаляй приложение с iPad до установки новой версии.

1. Скачай полный архив `QuietPages_STUDIO5_FULL_SOURCE.zip` и «Извлечь всё».
2. В GitHub Desktop проверь `quiet-pages-ipad`, ветку `main`, нажми `Fetch origin` / `Pull origin` при необходимости. Если есть незакоммиченные изменения, сначала разберись с ними, чтобы не затереть свою работу.
3. В GitHub Desktop: **Repository → Show in Explorer**; отдельно сделай копию существующей папки репозитория на рабочий стол.
4. В распакованном архиве открой `quiet-pages-ipad-main` и **скопируй её содержимое, а не папку целиком**, в открытую папку репозитория, с объединением и заменой файлов. **Не копируй `.git`, не удаляй `StickerPacks`**.
5. Вернись в GitHub Desktop, проверь, что появились изменения в `Sources`, `.github`, `QuietPages.xcodeproj`, `Resources/Assets.xcassets`.
6. Впиши в Summary `STUDIO 5.0 полный объединённый редактор` → **Commit to main → Push origin**.
7. Открой `https://github.com/marinaborisovna7177-png/quiet-pages-ipad/actions`, выбери последнюю сборку. При зелёной галочке скачай `QuietPages-IPA`, распакуй и получи `QuietPages-unsigned.ipa`.
8. Установи IPA через Sideloadly поверх существующего приложения с тем же Apple ID. **Не нажимай «Удалить приложение»**. Для бесплатной подписи обычно требуется повторная подпись через семь дней.
9. После установки проверь письмо после добавления наклейки, «Бумага» → «Зима», «Волшебство», кнопки «Двигать» / «Писать», создание собственных стикеров, запись PDF, резервную копию.

Если сборка красная, открой её Summary; внизу появится `QuietPages-Build-Log`. ZIP журнала можно передать ассистенту для адресного исправления ошибки.
