# Тихие страницы — MEGA 2000

Нативный SwiftUI-проект для iPad, рассчитанный на iPadOS 17.7.11 (iPad 6-го поколения).

**Библиотека:** 2000 отдельных PNG-стикеров (448×448 px, прозрачный фон), в 20 тематических коллекциях по 100 файлов. Каждый итоговый PNG имеет уникальные байты и уникальную композицию; **основные иллюстрированные мотивы встречаются в нескольких разных композициях**. Это не 2000 независимо нарисованных изображений. Точность Ингушских памятников или орнамента не заявляется: раздел «Горные легенды» — художественная фантазия.

В проекте сохранены предыдущие инструменты: бумага/шаблоны, обложки, изменение шрифтов и цвета, рукописные инструменты PencilKit, ластик, Undo/Redo, вставка и поворот наклеек, текст поверх наклеек, локальное хранение, импорт фото и PDF, экспорт PDF. Добавлена ранее утверждённая нежная иконка.

### Как загрузить на свой GitHub через GitHub Desktop
1. Распакуй **только обновление или полный проект** на компьютере.
2. В GitHub Desktop открой `quiet-pages-ipad` → **Show in Explorer**.
3. Скопируй папки **Sources**, **Resources**, **QuietPages.xcodeproj**, **StickerPacks** и **.github** в папку проекта с заменой.
4. В GitHub Desktop: Summary `Тихие страницы MEGA 2000` → **Commit to main** → **Push origin**. Если сетевые разрывы повторятся, отправляй 4 файла `StickerPacks/*.zip` отдельными коммитами по одному.
5. Открой GitHub → **Actions** → «Собрать приложение для iPad» → Run workflow → `main`.
6. Если сборка успешная, открой **Artifacts → QuietPages-IPA**, скачай и распакуй ZIP, установи unsigned IPA через Sideloadly со своим Apple ID.

### Важно
- Библиотека лежит **в ZIP-пакетах**, чтобы не приходилось вручную загружать 2000×2 файлов на GitHub. Сборка GitHub Actions распакует ZIP автоматически, перед запуском Xcode.
- Для офлайн-работы интернет не нужен после установки: изображения встраиваются в приложение.
- **Подтверждённой сборки Xcode и тестирования на реальном iPad здесь не было.** Проверен синтаксис Swift и содержимое пакетов. При ошибке присылай ZIP с логом GitHub Actions.
- Не удаляй установленное приложение с записанными заметками. Перед обновлением сохрани свои страницы в PDF. Сохраняй один и тот же bundle identifier / Apple ID.
- Цвета и иллюстрации созданы для цифрового дневника; 448 px недостаточно для крупноформатной печати с высоким DPI.
