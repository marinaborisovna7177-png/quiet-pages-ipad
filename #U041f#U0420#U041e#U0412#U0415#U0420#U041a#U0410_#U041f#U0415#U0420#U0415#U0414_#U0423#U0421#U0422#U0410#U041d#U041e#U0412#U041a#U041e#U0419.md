# Проверка «Тихих страниц»

## Что проверено автоматически здесь

- Синтаксис всех шести Swift-файлов: `swiftc -frontend -parse` — успешно.
- Структура проекта Xcode `.pbxproj`: `plutil -lint` — успешно.
- XML схемы Xcode и Info.plist — успешно.
- Все 18 указанных в программе стикеров и шесть обложек присутствуют в Asset Catalog.
- Проект содержит workflow облачной сборки IPA на macOS через GitHub Actions.

## Что ещё нельзя считать проверенным

- Проект не собран в Xcode и не запускался на реальном iPad 6.
- Возможны ошибки типизации и поведения UI, которые выявит только сборка и тестирование.
- Приоритетная проверка: установка IPA, рисование пальцем, создание нескольких страниц, перетаскивание стикеров, добавление фото, сохранение после закрытия, экспорт PDF и работа в авиарежиме.

## Очень важно

Это **исходный проект приложения**, не установочный IPA. Приобретать какие-либо функции внутри приложения не потребуется, но для установки понадобится сборка проекта и подпись. С бесплатной подписью Apple профили обычно действуют 7 дней.
